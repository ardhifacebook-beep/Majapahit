# Majapahit

Prototipe game county builder 3D berbasis browser dengan latar Majapahit dan lanskap tropis Jawa. Arah visualnya terinspirasi oleh CityRT.

## Dokumentasi

- [Pedoman visual, fondasi kode, dan checkpoint](docs/Pedoman_Visual_dan_Checkpoint.md)
- [Buka prototipe terrain](https://majapahit-terrain-ahs.vast-vine-9923.chatgpt.site)

Prototipe saat ini memiliki peta 125 × 125 tile dengan generator berbasis seed, sungai, hutan, perbukitan 3D, dan area studi 11 variasi aset Majapahit. Kode sumber checkpoint tersedia di folder `dist/`; buka `dist/index.html` melalui server web statis. Salinan ini tidak otomatis tersinkron dengan prototipe yang di-host.
